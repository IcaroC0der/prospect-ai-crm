# Especificação Funcional do Sistema
**ProspectAI CRM**
CRM Inteligente para Prospecção Comercial com Inteligência Artificial
**Versão:** 1.0

## 1. Objetivo
Desenvolver uma plataforma de prospecção comercial focada em geração de reuniões para empresas que vendem criação de sites, marketing digital, softwares e serviços B2B.

O sistema deve atuar como um **assistente comercial inteligente**, realizando automaticamente a pesquisa, qualificação e preparação dos leads, reduzindo drasticamente o tempo gasto em prospecção.
O usuário deve dedicar seu tempo apenas ao contato com o cliente.

## 2. Público-alvo
- SDRs
- Closers
- Agências de Marketing
- Fábricas de Sites
- Freelancers
- Empresas de Software
- Consultorias
- Prestadores de Serviços B2B

## 3. Objetivo Principal
Levar empresas desde a descoberta até o agendamento da reunião.
**Fluxo esperado:**
Pesquisa → Qualificação → Contato → Follow-up → Reunião → Cliente

O CRM não possui foco em vendas.
Seu foco é gerar reuniões qualificadas.

## 4. Dashboard

- Leads encontrados hoje

## 7. IA Prospectora
Principal diferencial do sistema.
Todos os dias às 06:00 a IA deverá pesquisar automaticamente novas empresas.

**Critérios:**
- Empresas brasileiras
- Nunca prospectadas
- Empresas ativas
- Contatos válidos

**Meta diária:**
30 empresas pesquisadas.
O sistema entregará automaticamente as 20 empresas com maior potencial.

## 33. Arquitetura Recomendada
- **Frontend:** React + Next.js
- **Backend:** NestJS
- **Banco:** PostgreSQL
- **Cache:** Redis
- **Busca:** Elasticsearch
- **IA:** OpenAI API + modelos especializados para análise e geração de conteúdo
- **Autenticação:** JWT + OAuth
- **Hospedagem:** Docker + VPS ou Kubernetes

## Visão do Produto
O ProspectAI CRM não deve ser apenas um CRM. Ele deve funcionar como um **copiloto comercial inteligente**, capaz de pesquisar oportunidades, analisar empresas, sugerir estratégias, preparar o vendedor para a ligação e aprender continuamente com os resultados obtidos. O objetivo é reduzir o tempo gasto em tarefas operacionais e aumentar a quantidade e a qualidade das reuniões geradas, tornando-se uma plataforma de prospecção orientada por inteligência artificial.
